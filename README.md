# UHH
Unified Harmonic Helper

## Generators

This repo includes Plop generators to scaffold apps and libraries.

- `app-node`: Node + TypeScript application scaffold
- `lib-ts`: TypeScript library scaffold

### Usage

- List generators: `npm run generate`
- Run interactively: `npm run generate`
- Quick alias: `npm run g`

You will be prompted for a name and options. Output goes to:

- Apps: `apps/<your-name>`
- Libraries: `packages/<your-name>`
