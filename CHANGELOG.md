# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2025-10-20

### Added
- Initial release of Unified Harmonic Helper (UHH)
- HarmonicField class for computing harmonic fields
  - 2D harmonic fields using Fourier series
  - 3D harmonic fields using spherical harmonics
  - Wave superposition from multiple sources
  - Gradient and Laplacian computation
  - Energy calculation
  - Boundary condition support
- HarmonicVisualizer class for scientific visualization
  - 2D heatmap visualization with contours
  - 3D surface plotting
  - Vector field visualization
  - Support for matplotlib and plotly backends
  - Time evolution animation support
- Comprehensive example scripts
  - Basic 2D visualization
  - Gradient and vector field visualization
  - 3D harmonic fields
  - Time evolution demos
  - Full demonstration script
- Complete test suite with 22 unit tests
- Detailed documentation and API reference
- Setup and installation scripts
